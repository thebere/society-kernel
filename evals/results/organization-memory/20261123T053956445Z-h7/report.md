## Research question

When a new situation is structurally related to a previous episode but has different literal referents, does organization-memory reinstatement improve task outcome or computational efficiency relative to reasonable alternatives?

## Conditions

No memory uses the unchanged Society cycle. Organization memory adds one top recalled match's production H6 activation Effects before propagation. Direct routing unions the fixed semantic concept-to-capability table for positive signals. Episode retrieval replays the nearest stored episode's routing recommendation, falling back to direct routing when no positive match exists. All conditions receive the same observations, capabilities, four-assessment budget, common execution scheduler, and scorer. See the [frozen suite specification](../../../suites/organization-memory/README.md) and recoverable source snapshot for exact policies.

## Dataset

Memory formation: 8 cases. Held-out: 32 distinct cases, eight each related, partial, unrelated, misleading. All five role occupants differ between formation and held-out episodes. No held-out outcomes were used for memory formation, routing rules, parameter tuning, or registration. [inputs.json](inputs.json) preserves facts, concepts, requirements, configuration, and routing table.

## Primary metric

Task coverage = unique required findings produced by executed assessments / unique required findings. It is not coalition agreement. Conditional handlers derive findings from current facts; several different capabilities can satisfy overlapping requirements. Every case has at least one requirement.

## Secondary metrics

Local handler executions, selected agencies, actual threshold recruits, all dispatch requests, unnecessary executions (a handler produces no required finding), skipped assessments, recall comparisons, and reinstatement Effects. Direct/replay policies bypass recruitment, so their actual threshold-recruit count is zero; selected count is provided for comparing organization size. All counts are deterministic work proxies. No measured latency, energy, amortized gain, significance test, or population generalization is claimed.

## Interpretation

Mixed under protocol v1: organization memory improved mean task coverage over no memory, but did not establish a consistent quality-and-cost advantage over the declared alternatives.

This is the predeclared descriptive classification, not a claim of broad scientific support. The full class and baseline comparisons govern the scope; increased coverage alone establishes no efficiency advantage. Misleading cases expose boundaries relevant to H8/H11 but do not complete those investigations.

## Limitations

Deterministic mock domain; small sample; hand-authored task requirements, facts, concepts, and semantic routing table; simple Jaccard similarity; fixed canonical agency priority and four-assessment budget; no stochastic capabilities; no real LLM/tool/API calls; no claim of cognitive validity, realistic business performance, general agent benefit, biological plausibility, cross-domain superiority, sophisticated-planner advantage, or production usefulness. Memory-only and no-memory use graded activation while the direct baseline uses signal presence. Baseline schedules and handlers are matched, but selection mechanisms differ by design. Findings have only informational value; negative effects are omissions and budget displacement, not harmful business actions. No utility selection, aggregation, forgetting, or H6 modification was made.

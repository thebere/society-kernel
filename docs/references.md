# References

This is the shared bibliography for the research documents and evaluation protocols. Entries identify intellectual sources and comparison points; citing a source does not establish a Society Kernel claim or imply that an evaluation against that source's architecture exists.

## R1: K-lines

Minsky, Marvin. *K-Lines: A Theory of Memory*. MIT Artificial Intelligence Laboratory, AI Memo 516, June 1979. [MIT repository and source files](https://dspace.mit.edu/entities/publication/6dc33036-2c59-42d2-be14-ae0151019598).

The journal version appeared in *Cognitive Science*, volume 4, pages 117–133, in 1980; see [Minsky's bibliography](https://www.mit.edu/~dxh/marvin/web.media.mit.edu/~minsky/Bibliography.html). The memo and journal version have different publication dates and should be identified explicitly when citing a particular passage.

**Role:** historical source for the K-line proposal and partial-state reinstatement. Society Kernel's explicit records, concept-set similarity, and capability configuration are engineering interpretations whose usefulness remains to be evaluated.

## R2: Society of Mind

Minsky, Marvin. *The Society of Mind*. Simon & Schuster, 1986. [Publisher page](https://www.simonandschuster.com/books/Society-Of-Mind/Marvin-Minsky/9780671657130); the linked paperback edition was published in 1988.

**Role:** intellectual source for agencies and the terminology used in the project. The implementation is not a faithful reproduction of the book or a biological validation of its proposals.

## R3: ACT-R

Anderson, John R.; Bothell, Daniel; Byrne, Michael D.; Douglass, Scott; Lebiere, Christian; and Qin, Yulin. *An Integrated Theory of the Mind*. 2004. [Author-institution repository](https://kilthub.cmu.edu/articles/journal_contribution/An_Integrated_Theory_of_the_Mind/6613469).

**Role:** comparison literature on cognitive architecture and the integration of specialized modules. No ACT-R benchmark adapter or comparative result is currently provided by this repository.

## R4: Soar

Laird, John E. *The Soar Cognitive Architecture*. MIT Press, 2012. [Publisher page](https://mitpress.mit.edu/9780262122962/the-soar-cognitive-architecture/).

**Role:** comparison literature on integrated cognitive architecture, reasoning, and learning. A future Soar comparison must identify the implemented version and task adaptation rather than use the book as a substitute for an executable baseline.

## Adding sources

Use stable reference IDs and verified author, title, year, edition/version, and primary URL or DOI. Record the specific role: historical proposal, established empirical finding, baseline design/implementation, method, or dataset. Add page/section locators for claims tied to particular passages, and distinguish the source's claim from the project's interpretation.

The current bibliography is a starting point, not a completed related-work review. Protocols for case-based reasoning, agent memory/orchestration, learning, and cognitive evaluation must add the sources actually used, including dataset and implementation provenance. Preserve source/version identity in run artifacts when it affects a comparison.
